# G4R Website Tester

Static Amazon affiliate search-link tester for Garage Reorder by 4DAT.

Open `index.html` directly or serve this folder with any static server. The tester:

- Builds Amazon search URLs with `tag=4dat-20`.
- Labels the Amazon CTA as a paid link.
- Keeps a local browser-only audit log in `localStorage`.
- Avoids Amazon prices, ratings, availability, reviews, and Amazon product images.

Required public pages are included as static starter pages:

- `affiliate-disclosure.html`
- `privacy.html`
- `terms.html`
- `support.html`
